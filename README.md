# Supergood Solutions

This repository is the static site for [supergood.solutions](https://supergood.solutions/). It is served by GitHub Pages with no build step. Supergood designs and builds AI agents and workflow automation for marketing and operations teams.

## Links

- [Supergood Solutions](https://supergood.solutions/): the live site.
- [Supergood API documentation](https://supergood.solutions/developers/): how to read the rate card and service list, and how to submit a fit check. No API key needed.
- [openapi.json](https://supergood.solutions/openapi.json): the OpenAPI 3.1 contract for the API.
- [Supergood MCP server](https://supergood.solutions/developers/): the MCP server section of the developer docs, for the server at `https://api.supergood.solutions/api/mcp`, with tools `get_pricing`, `get_services` and `submit_fit_check`.
- [llms.txt](https://supergood.solutions/llms.txt): a summary of the site for language models.
- [AGENTS.md](AGENTS.md): rules for coding agents and AI assistants working in this repo.

## Editing

Blog posts, the blog index and the post entries in `sitemap.xml` are generated by an automated publisher, so do not edit them by hand. Prices come from the [pricing page](https://supergood.solutions/pricing/). Read AGENTS.md before you change anything.
