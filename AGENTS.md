# AGENTS.md

This repository is the static site for https://supergood.solutions. GitHub Pages serves the root of the default branch. There is no build step and no package manager. A file you add or edit at the root is served as written, and `.nojekyll` is present, so every file in the repo is public.

## Where machine-readable content lives

- `/llms.txt` and `/llms-full.txt`: site summary and full text for language models.
- `/openapi.json`: OpenAPI 3.1 description of the public API.
- `/pricing.json` and `/services.json`: the rate card and the service list as JSON.
- Each page has a Markdown twin next to it. `/pricing/` has `/pricing.md`, and `/developers/` has `/developers.md`.
- `/.well-known/agent-skills/index.json`: the agent skills index.
- `/.well-known/ard.json`: the discovery catalog of the site's agent resources.
- `/plugin/`: an Agent Plugins package (`plugin.json`, `mcp.json`, `skills/`) bundling the public skills and the MCP server. Its skill files are copies of the ones in `/.well-known/agent-skills/`; keep them in sync.
- `/server.json`: the MCP Registry entry for the hosted MCP server, published with `mcp-publisher`.
- `/sdk/`: source of the `supergood-solutions` npm package (SDK and CLI).

## Public API and MCP server

The Supergood API documentation is at https://supergood.solutions/developers/ and the contract is `/openapi.json`. No API key, token or account is needed.

- `GET https://supergood.solutions/pricing.json` and `GET https://supergood.solutions/services.json` are static reads.
- `POST https://api.supergood.solutions/api/v1/intake` submits a fit check and emails the site owner. Send an `Idempotency-Key` header with it.
- `POST https://api.supergood.solutions/api/v1/sandbox/intake` takes the same body, validates it and sends nothing. Use it for every test.
- `GET https://api.supergood.solutions/api/v1/posts` lists blog posts newest first with cursor pagination (`limit`, `cursor`, `next_cursor`).
- `GET` or `POST https://api.supergood.solutions/ask` is an NLWeb 0.55 endpoint: ask a question, get the blog posts that answer it. SSE with `streaming=true`.

The Supergood MCP server is at `https://api.supergood.solutions/api/mcp` (Streamable HTTP, no key). Its tools are `get_pricing`, `get_services` and `submit_fit_check`. Only `submit_fit_check` has a side effect.

## Rules for edits

- Blog posts, `blog/index.html` and the post entries in `sitemap.xml` are generated by an automated publisher. Do not hand-edit them. Hand-added non-post sitemap entries are preserved by the publisher.
- Prices and commercial terms come from https://supergood.solutions/pricing/ and `/pricing.json`. Never invent or change a price, a term or a number in an unrelated edit. If a price must change, change the pricing page, `pricing.json`, `pricing.md`, and every other place that quotes it, in one deliberate edit.
- Keep `openapi.json` valid OpenAPI 3.1. Do not rename an `operationId` or a path.
- Do not commit secrets, credentials or private notes. The repo is public.
